# Reference Style → Article → Scene

1. Input
   - Reference text
   - New topic

2. Analysis
   - Extract structure, presentation, tone, pacing, and recurring characteristics.

3. Create
   - Write a new original article about the new topic using the extracted characteristics.

4. Scene
   - Divide the article into coherent scenes.
   - Create a visual prompt and duration for each scene.

5. Output
   - Return structured data to the calling tool.
   - Do not assume Excel or storage implementation.

The desktop application owns file creation and storage.
